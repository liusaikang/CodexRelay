## 新增测试关注点

- 沙箱枚举及环境变量校验、新建/续接线程传参、HTTP/MCP 接受原生权限参数并拒绝非法值。
- 每轮任务权限、排队重启保持权限、重试保留原权限、幂等键参数冲突、旧完整权限会话哈希向后兼容；未替代目标主机真实沙箱验收。

- 队列分页、筛选、等待原因、接收次序与实际可调度次序的区别。
- 取消时重复操作、用户关闭确认框后按钮恢复。
- 重试只接受失败终态；新会话、新任务 ID、原始问题与上下文、原任务关联。
- 同一重试键并发调用去重，并在重启后保留。
- 前序失败放行与新会话重试是不同操作。
- 未登录、非法筛选参数、缺失重试键均被拒绝。
- 浏览器重试请求结果不确定时，同标签页刷新后仍复用同一幂等键。
- 延迟重试响应不改变后来选中的会话或草稿；已接收后的页面同步失败明确提示新任务 ID。
- MCP 提交使用完整严格 schema，额外的目录/模型参数被拒绝，不再静默剔除。
